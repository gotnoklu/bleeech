# Button

The Button component is a versatile interactive element that triggers actions when clicked. It supports multiple variants, sizes, shapes, and can display text, icons, or custom content.

## Basic Usage

The simplest button displays text content with a filled background.

<CodeExample codes={BasicCodes} />

## Variants

Buttons support three visual variants: `filled` (solid background), `outlined` (border only), and `ghost` (transparent background).

<CodeExample codes={VariantCodes} />

## Shapes

Buttons support two shape variants: `default` (rounded rectangle) and `rounded` (fully rounded pill).

<CodeExample codes={ShapeCodes} />

## Sizes

Buttons come in three predefined sizes: `sm` (32px), `md` (40px), and `lg` (48px).

<CodeExample codes={SizeCodes} />

## Icon Buttons

Icon buttons are square buttons that display only an icon. Use the `icon`, `icon-sm`, `icon-md`, or `icon-lg` size values to create icon buttons.

<CodeExample codes={IconButtonCodes} />

## Disabled State

Disabled buttons cannot be pressed and have reduced opacity to indicate their inactive state.
